# Lesson podcasts

Put one audio file per lesson and language in this folder. When a file with the
right name is here, a "Listen to the lesson podcast" player appears on that
lesson's Learn card. Lessons without a file simply show no player.

## File names

`<lesson id>-<language>.<ending>`

- language: `en` for the English page, `ar` for the Arabic page
- ending: `.m4a`, `.mp3` or `.wav`
